# Module 4: plotting and fitting

What goes here:

- `planets_plot.py` and the figure it saves (`planets.png`): your own copy of `planets_plot_starter.py` (the ten planets, plotted). Run it from the repository folder: `python module-4/planets_plot.py`. Everyone keeps their own file.
- `distributions.ipynb`: your own copy of `distributions_starter.ipynb`, the first notebook. Open it in VS Code and pick the `astr119` kernel; a notebook runs in its own folder, so the figures it saves land here.
- `squarespare.py`, `spec.md` and the PNG for HW4. Copy `squarespare_starter.py`, commit, work on the copy.
- `ai-use-note.md` and your exported transcripts.

Starter files: `planets_plot_starter.py`, `distributions_starter.ipynb`, `squarespare_starter.py`. The galaxy notebook and the catalog it reads are added to this folder later in the module; `git pull` when told.
