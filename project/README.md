# Final project

Your project lives in this folder: draft, code, figures, report, and AI-use log. Commit as you go; `git log` is part of your process record and is looked at in the oral exam.

| Date | Deliverable |
|---|---|
| Thu Nov 12 | Project draft (`proposal.md`; template below) plus a photo of your handwritten planning |
| Nov 17 and Nov 19 | Informal check-ins in class |
| Nov 19 to Dec 3 | The oral exam, in class: your project well under way, explained and modified live |
| Thu Dec 3 | Last day: some projects presented |
| Wed Dec 9 | Code and figures; two-page report with AI-use log (`report.md`) |

Suggested layout once you start: your scripts or notebook at the top level of this folder, `figures/` for output plots, `data/` for any project data set (keep it under a few megabytes; do not commit `.fits` files).

Templates: `proposal-template.md`, `report-template.md`. The project menu and the rubric are on Canvas (Module 6).
